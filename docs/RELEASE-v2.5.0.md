周迹 v2.5.0：多彩统计与本地歌单

- 课表采用 12 种高区分度自然色，同名任务仍保持同色。
- 专注环图使用森林绿、柔黄、湖蓝、珊瑚色、薰衣草紫等色彩，多个科目更容易区分。
- 支持从 Android 文件选择器一次导入多首本地音频，歌单会持久保存并在专注时顺序循环播放。
- 单曲与歌单均支持试听、暂停、继续和随专注结束停止；番茄完成铃声保持独立播放。
- 界面说明标明网易云音乐、QQ 音乐在线歌单所需的平台授权条件。
- 数据库升级到 V7，保留旧版本的计划、记录、专注数据和设置。

已通过 Flutter analyze 和全部 59 项自动测试。安装包可以直接覆盖 v2.4.0。
