周迹 v2.3.0：专注自动回填计划，时间表更紧凑

- 常用专注开始后立即写入当前计划；当前时段已有其他任务时，以实际执行的专注任务替换。
- 直接使用主番茄钟时，继续自动关联此刻正在进行的计划。
- 删除分类选择和分类管理，专注统计直接按任务名称汇总。
- 同名任务稳定使用同一颜色，旧任务会在自动配色开启时统一。
- 修复低倍率下任务卡错位、大小不一和文字靠左；任务严格对齐时间线，字体自动缩放并居中。
- 压缩计划页顶部工具栏，增加时间表可视面积。
- 长按空白时间后可向上或向下滑动创建计划，并改善触觉反馈和拖动按钮样式。
- 统计页改为绿色背景、绿色指标和绿色图表。

已通过 Flutter analyze 和全部 54 项自动测试。安装包可以直接覆盖 v2.2.1，原有计划、记录、专注数据和设置会保留。
