周迹 v2.2.0：常用专注卡片、全天计划和专注统计

- 时间轴默认 00:00–24:00，右上角可配置 06:00 或跨天至次日 06:00，时间选择器统一使用 24 小时制。
- 在“专注 → 常用专注 → 新建”保存“数学 60 分钟”等任务，支持直接开始、长按编辑／删除，以及正向计时。
- 直接开始普通专注时默认使用当前计划；计划可独立设置专注分钟数，并可开启“完成专注后完成计划”。
- 可选择手机本地音频作为循环背景音乐。
- 压缩计划页操作栏，支持自动配色，活动记录可以设置为未完成。
- 统计页新增累计专注、当日专注、日／周／月／自定义时长分布和本月 24 小时时段分布。
